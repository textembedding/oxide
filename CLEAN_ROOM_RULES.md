# Clean-Room Rules

1. The legacy repository is quarantined and must not be mounted into or
   disclosed to implementation sessions.
2. Do not copy legacy code, tests, schemas, handoffs, Git history, or
   architecture documents.
3. Only human-reviewed Stage 0–3 requirements may cross into this repository.
4. A missing requirement is a blocker, not permission to invent a subsystem.
5. A failed acceptance check does not authorize scope expansion.
6. Every milestone has allowed files, a source-line ceiling, acceptance
   commands, explicit non-goals, and a stop boundary.
7. The implementer does not independently expand the contract.
