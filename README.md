# Swarm Harness — Clean-Room Bootstrap

This repository is a deliberately small Python harness and disposable
SQLite journal prototype. Its purpose is to coordinate workers implementing
Stages 0–3 of the production Rust kernel while proving the journal layer's
two-tool contract.

Start with:

1. `HARNESS_CONTRACT.md`
2. `NON_GOALS.md`
3. `ACCEPTANCE.md`
4. `CLEAN_ROOM_RULES.md`
5. `prompts/01-journal.md`

The production stage manifests remain disabled until the Stage 0–3 product
requirements have been manually reviewed and copied into this repository.
